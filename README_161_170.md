# Programs 161–170: Regular Expressions and Automata Analysis

Ten standalone C11 programs illustrating regex compilation and automata algorithms. They build on the previous 160 examples and are not general-purpose industrial libraries.

| # | Source | What it does | How to run |
|---:|---|---|---|
| 161 | [`161_regex_postfix_thompson.c`](programs/161_regex_postfix_thompson.c) | Compile postfix regex to a Thompson ε-NFA and simulate it | `<postfix-regex> <word>` |
| 162 | [`162_regex_infix_to_postfix.c`](programs/162_regex_infix_to_postfix.c) | Convert binary infix regex with implicit concatenation to postfix | `<infix-regex>` |
| 163 | [`163_dfa_transition_cover.c`](programs/163_dfa_transition_cover.c) | Construct a shortest-prefix transition coverage suite using BFS | Built-in example |
| 164 | [`164_dfa_shortest_reset_word.c`](programs/164_dfa_shortest_reset_word.c) | Find a shortest synchronizing word by subset BFS | Built-in example |
| 165 | [`165_dfa_tarjan_scc.c`](programs/165_dfa_tarjan_scc.c) | Compute strongly connected components of a DFA using Tarjan's algorithm | Built-in example |
| 166 | [`166_dfa_left_quotient.c`](programs/166_dfa_left_quotient.c) | Evaluate a left quotient of the ends-in-01 language | `<prefix> <suffix>` |
| 167 | [`167_dfa_right_quotient.c`](programs/167_dfa_right_quotient.c) | Compute DFA final states for right quotient by suffix 01 | `<word>` |
| 168 | [`168_reversed_dfa_nfa.c`](programs/168_reversed_dfa_nfa.c) | Reverse all transitions of a DFA to recognize its reverse language | `<word>` |
| 169 | [`169_dfa_state_pair_witnesses.c`](programs/169_dfa_state_pair_witnesses.c) | Find shortest distinguishing words for every DFA state pair | Built-in example |
| 170 | [`170_nfa_dfa_exhaustive_crosscheck.c`](programs/170_nfa_dfa_exhaustive_crosscheck.c) | Exhaustively compare NFA and DFA recognition through length eight | Built-in example |

## Examples

```sh
make
./bin/162_regex_infix_to_postfix '(0|1)*01'
./bin/161_regex_postfix_thompson '01|*0.1.' '1101'
./bin/164_dfa_shortest_reset_word
./bin/170_nfa_dfa_exhaustive_crosscheck
python3 tests/test_programs_161_170.py
```

The postfix regex uses `.` for concatenation, `|` for union, and `*` for Kleene star. Only binary literal symbols `0` and `1` are supported. The Thompson builder caps construction at 62 states. Programs 163–165 and 169–170 analyze built-in automata, while 166–168 demonstrate particular regular-language transformations. Program 170 checks every binary word of lengths 0 through 8 (511 words).
