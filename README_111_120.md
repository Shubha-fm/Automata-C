# Programs 111–120

Ten new C11 standalone recognizers, extending the repository's numeric and alphabet-based examples.

- [111_dfa_binary_mod_17.c](programs/111_dfa_binary_mod_17.c): Binary number divisible by 17
- [112_dfa_decimal_mod_7.c](programs/112_dfa_decimal_mod_7.c): Decimal number divisible by 7
- [113_dfa_ternary_mod_5.c](programs/113_dfa_ternary_mod_5.c): Ternary number divisible by 5
- [114_dfa_a_count_mod_4.c](programs/114_dfa_a_count_mod_4.c): Number of a symbols divisible by 4
- [115_dfa_ends_aba.c](programs/115_dfa_ends_aba.c): Strings over a,b ending in aba
- [116_dfa_contains_bbaa.c](programs/116_dfa_contains_bbaa.c): Strings over a,b containing bbaa
- [117_dfa_even_a_and_ends_b.c](programs/117_dfa_even_a_and_ends_b.c): Even a count and ends in b
- [118_dfa_no_adjacent_a.c](programs/118_dfa_no_adjacent_a.c): No consecutive a symbols
- [119_dfa_exactly_two_b.c](programs/119_dfa_exactly_two_b.c): Exactly two b symbols
- [120_dfa_length_mod_5.c](programs/120_dfa_length_mod_5.c): Word length divisible by five over a,b

Run `make` and then `python3 tests/test_programs_111_120.py`.
