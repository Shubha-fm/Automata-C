# Programs 291–300: DFA Testing, Distances, and Formal Verification

Ten independently compiled ISO C11 programs use the shared complete binary DFA file format defined in [`include/dfa_io.h`](include/dfa_io.h). The new batch adds dynamic traces, coverage measurements, approximate word recognition, a pattern-avoidance transformation, and model-checking witnesses.

| # | Program source | Purpose |
|---:|---|---|
| 291 | [`291_dfa_file_execution_trace.c`](programs/291_dfa_file_execution_trace.c) | Execute a DFA word and print the visited-state trace |
| 292 | [`292_dfa_file_shortest_extension.c`](programs/292_dfa_file_shortest_extension.c) | Shortest accepted extension of an input prefix |
| 293 | [`293_dfa_file_word_coverage.c`](programs/293_dfa_file_word_coverage.c) | Visited-state and transition coverage for a word |
| 294 | [`294_dfa_file_levenshtein_distance.c`](programs/294_dfa_file_levenshtein_distance.c) | Exact insertion/deletion/substitution distance to a regular language |
| 295 | [`295_dfa_file_nearest_hamming.c`](programs/295_dfa_file_nearest_hamming.c) | Nearest same-length accepted word with lexicographic tie-breaking |
| 296 | [`296_dfa_file_avoid_pattern.c`](programs/296_dfa_file_avoid_pattern.c) | Construct DFA intersection with a substring-avoidance constraint |
| 297 | [`297_dfa_file_safety_lasso.c`](programs/297_dfa_file_safety_lasso.c) | Shortest violation of universal safety with an infinite lasso |
| 298 | [`298_dfa_file_batch_monitor.c`](programs/298_dfa_file_batch_monitor.c) | Evaluate a file of binary traces and summarize verdicts |
| 299 | [`299_dfa_file_buchi_lasso.c`](programs/299_dfa_file_buchi_lasso.c) | Find a reachable accepting cycle and a Büchi lasso witness |

```bash
./bin/291_dfa_file_execution_trace machine.dfa 00101

```

## Semantics

Program 294 computes full Levenshtein distance between a binary word and the set of accepted words (insertion, deletion and substitution have unit cost). If the accepted language is empty, it reports `EMPTY_LANGUAGE`. Program 295 searches accepted words of the **same length**, minimizing Hamming distance and choosing the lexicographically earliest tie. Program 296 computes `L(DFA) ∩ {w : PATTERN is not a contiguous substring of w}`, outputting a compatible DFA file. For program 297, accepting states represent *safe* states and the shortest path to a reachable rejecting state is a finite safety counterexample. Its extension is described by `TAIL_ZEROS` and `LOOP_ZEROS` from the violating state. Program 299 interprets accepting states as a Büchi acceptance set: `BUCHI_NONEMPTY` means some infinite binary word visits accepting states infinitely often, with a prefix and nonempty cycle witness. Program 300 partitions reachable states by equivalence of their residual languages, and indicates whether all reachable states are pairwise distinguishable.

## Limits

Individual input words are limited to 4,096 symbols for traces and coverage, 40 symbols for edit distance, and 128 for nearest-Hamming recognition. Pattern avoidance allows patterns of length 1–30 and requires the DFA product to fit in 32 states. The batch monitor reads one binary word per line; an empty line denotes the empty word. Transformation output (296) uses the same file format as programs 241–290.

The regression suite cross-checks outputs with independent Python reference algorithms on example and seeded random automata, including exact shortest witnesses, edit distances, accepting cycles, pattern avoidance, and equivalence-class partitions.
