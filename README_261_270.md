# Programs 261–270: Language Operations and Closure for File-Based DFAs

Ten new ISO C11 command-line programs compatible with the shared [file-based DFA format](README_241_250.md). They read complete binary DFAs (up to 32 states) and, except for the property-checking commands 267–268, output a new complete DFA using the same format.

| # | Source | Purpose |
|---:|---|---|
| 261 | [`261_dfa_file_union.c`](programs/261_dfa_file_union.c) | Language union by DFA product |
| 262 | [`262_dfa_file_difference.c`](programs/262_dfa_file_difference.c) | Language difference by DFA product |
| 263 | [`263_dfa_file_left_quotient.c`](programs/263_dfa_file_left_quotient.c) | Left quotient of a language by a fixed binary prefix |
| 264 | [`264_dfa_file_right_quotient.c`](programs/264_dfa_file_right_quotient.c) | Right quotient of a language by a fixed binary suffix |
| 265 | [`265_dfa_file_prefix_closure.c`](programs/265_dfa_file_prefix_closure.c) | Prefix closure of a regular language |
| 266 | [`266_dfa_file_suffix_closure.c`](programs/266_dfa_file_suffix_closure.c) | Suffix closure using reachable-state subset determinization |
| 267 | [`267_dfa_file_prefix_free_witness.c`](programs/267_dfa_file_prefix_free_witness.c) | Prefix-free property check with a counterexample |
| 268 | [`268_dfa_file_length_spectrum.c`](programs/268_dfa_file_length_spectrum.c) | Accepted-word length spectrum through a finite bound |
| 269 | [`269_dfa_file_right_ideal.c`](programs/269_dfa_file_right_ideal.c) | Right ideal closure LΣ* |
| 270 | [`270_dfa_file_left_ideal.c`](programs/270_dfa_file_left_ideal.c) | Left ideal closure Σ*L |

## Usage

```sh
make test-261-270
./bin/261_dfa_file_union a.dfa b.dfa > union.dfa
./bin/262_dfa_file_difference a.dfa b.dfa > difference.dfa
./bin/263_dfa_file_left_quotient a.dfa 01 > left_quotient.dfa
./bin/264_dfa_file_right_quotient a.dfa 01 > right_quotient.dfa
./bin/265_dfa_file_prefix_closure a.dfa > prefixes.dfa
./bin/266_dfa_file_suffix_closure a.dfa > suffixes.dfa
./bin/267_dfa_file_prefix_free_witness a.dfa
./bin/268_dfa_file_length_spectrum a.dfa 20
./bin/269_dfa_file_right_ideal a.dfa > right_ideal.dfa
./bin/270_dfa_file_left_ideal a.dfa > left_ideal.dfa
```

## Definitions

For binary alphabet Σ={0,1}: the left quotient by `w` is `w⁻¹L={x : wx∈L}`, and the right quotient by `w` is `L/w={x : xw∈L}`. Prefix closure includes every prefix of a word in L; suffix closure includes every suffix of a word in L. The right ideal is `LΣ*` and the left ideal is `Σ*L`. A prefix-free language contains no pair of accepted words where one is a **proper** prefix of the other. Program 267 prints an accepted prefix and an accepted extension when this property fails. Program 268 reports precisely which lengths up to the requested bound admit at least one accepted word (not how many words exist at those lengths).

## Limits and testing

The union and difference commands build the complete Cartesian product, so `|QA|×|QB|` must not exceed 32 states. The suffix closure and left ideal commands determinize subsets and accept input DFAs of at most 10 states, rejecting an output that exceeds 32 states. Quotient parameters are limited to 4,096 binary symbols. The length spectrum bound is at most 10,000. The suite compares outputs to independently implemented Python language-oracles, including random machines, and checks incorrect input handling. Generated DFA files are compatible with the earlier [programs 241–260](README_241_250.md).
