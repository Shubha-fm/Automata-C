# Programs 151–160: automata construction and analysis

These ten standalone C11 programs explore formal-language algorithms beyond pattern recognizers. Every program uses a small, documented example machine. Examples that take an argument are labeled below.

| No. | Source | Demonstration | Input |
|---:|---|---|---|
| 151 | [`151_epsilon_nfa_cycle_simulator.c`](programs/151_epsilon_nfa_cycle_simulator.c) | Epsilon-NFA simulation with a cyclic epsilon closure | Command-line argument |
| 152 | [`152_epsilon_nfa_subset_construction.c`](programs/152_epsilon_nfa_subset_construction.c) | Reachable DFA subsets from an epsilon-NFA | Built-in example |
| 153 | [`153_dfa_shortest_rejected_word.c`](programs/153_dfa_shortest_rejected_word.c) | Find the shortest rejected word using BFS | Built-in example |
| 154 | [`154_dfa_shortest_access_words.c`](programs/154_dfa_shortest_access_words.c) | Shortest access words for every reachable DFA state | Built-in example |
| 155 | [`155_dfa_finiteness_productive_cycle.c`](programs/155_dfa_finiteness_productive_cycle.c) | Decide language finiteness by finding productive cycles | Built-in example |
| 156 | [`156_dfa_count_accepted_words.c`](programs/156_dfa_count_accepted_words.c) | Dynamic programming counts accepted words of a given length | Command-line argument |
| 157 | [`157_nfa_count_accepting_paths.c`](programs/157_nfa_count_accepting_paths.c) | Count accepting runs of a nondeterministic automaton | Command-line argument |
| 158 | [`158_mealy_equivalence_witness.c`](programs/158_mealy_equivalence_witness.c) | Find the shortest distinguishing word for two Mealy machines | Built-in example |
| 159 | [`159_right_linear_grammar_recognizer.c`](programs/159_right_linear_grammar_recognizer.c) | Right-linear grammar recognition via an equivalent NFA | Command-line argument |
| 160 | [`160_dfa_canonical_bfs_encoding.c`](programs/160_dfa_canonical_bfs_encoding.c) | Canonical reachable-state renumbering of a sample DFA | Built-in example |

## Build and test

```sh
make
python3 tests/test_programs_151_160.py
./bin/151_epsilon_nfa_cycle_simulator 10101
./bin/156_dfa_count_accepted_words 4
./bin/157_nfa_count_accepting_paths 0101
./bin/159_right_linear_grammar_recognizer 001001
```

The epsilon-NFA conversion, BFS, finiteness and Mealy examples print results for built-in machines. They are teaching implementations, not full parsers for arbitrary input automata. Program 156 supports lengths 0–32 and program 157 supports at most 32 binary symbols.
