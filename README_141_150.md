# Programs 141–150: Positional Number DFAs

Ten standalone C11 programs track the numeric remainder as each digit is read. They accept nonempty unsigned representations of multiples of the stated divisor. Leading zeroes are permitted.

- [141_dfa_binary_mod_29.c](programs/141_dfa_binary_mod_29.c): Binary integer divisible by 29
- [142_dfa_binary_mod_31.c](programs/142_dfa_binary_mod_31.c): Binary integer divisible by 31
- [143_dfa_decimal_mod_13.c](programs/143_dfa_decimal_mod_13.c): Decimal integer divisible by 13
- [144_dfa_hex_mod_7.c](programs/144_dfa_hex_mod_7.c): Hexadecimal integer divisible by 7
- [145_dfa_ternary_mod_7.c](programs/145_dfa_ternary_mod_7.c): Ternary integer divisible by 7
- [146_dfa_quaternary_mod_5.c](programs/146_dfa_quaternary_mod_5.c): Base-4 integer divisible by 5
- [147_dfa_binary_mod_37.c](programs/147_dfa_binary_mod_37.c): Binary integer divisible by 37
- [148_dfa_decimal_mod_17.c](programs/148_dfa_decimal_mod_17.c): Decimal integer divisible by 17
- [149_dfa_octal_mod_9.c](programs/149_dfa_octal_mod_9.c): Octal integer divisible by 9
- [150_dfa_hex_mod_11.c](programs/150_dfa_hex_mod_11.c): Hexadecimal integer divisible by 11

Run `make` followed by `python3 tests/test_programs_141_150.py`.
