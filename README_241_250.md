# Programs 241–250: File-Based DFA Toolkit

Ten independently compiled C11 command-line tools share [`include/dfa_io.h`](include/dfa_io.h) for loading and writing a complete deterministic binary finite automaton. Outputs from programs 245–248 are valid inputs to the other tools.

| # | Source | Purpose |
|---:|---|---|
| 241 | [`241_dfa_file_inclusion.c`](programs/241_dfa_file_inclusion.c) | DFA language inclusion with shortest counterexample |
| 242 | [`242_dfa_file_shortest_word.c`](programs/242_dfa_file_shortest_word.c) | Shortest accepted word via breadth-first search |
| 243 | [`243_dfa_file_word_count.c`](programs/243_dfa_file_word_count.c) | Count accepted words of specified length modulo 1,000,000,007 |
| 244 | [`244_dfa_file_scc_audit.c`](programs/244_dfa_file_scc_audit.c) | Reachable strongly connected components and accepting-cycle audit |
| 245 | [`245_dfa_file_complement.c`](programs/245_dfa_file_complement.c) | Produce a complete DFA for the complement language |
| 246 | [`246_dfa_file_intersection.c`](programs/246_dfa_file_intersection.c) | Construct the DFA product for language intersection |
| 247 | [`247_dfa_file_reachable_trim.c`](programs/247_dfa_file_reachable_trim.c) | Remove unreachable DFA states with canonical BFS numbering |
| 248 | [`248_dfa_file_minimize.c`](programs/248_dfa_file_minimize.c) | Minimize a DFA by partition refinement |
| 249 | [`249_dfa_file_state_pair_witnesses.c`](programs/249_dfa_file_state_pair_witnesses.c) | Find shortest distinguishing words for all DFA state pairs |
| 250 | [`250_dfa_file_graphviz.c`](programs/250_dfa_file_graphviz.c) | Export a DFA to Graphviz DOT |

## File format

Each input file has three sections: `n start`, exactly `n` accepting flags (`0` or `1`), and exactly `n` rows containing two target states (`on0 on1`). State numbers are zero-based. Only complete deterministic binary DFAs with 1–32 states are accepted. Extra tokens, missing transitions, and out-of-range states are rejected.

Example, a three-state DFA accepting strings ending with `01`:

```text
3 0
0 0 1
1 0
1 2
1 0
```

## Build and run

```sh
make test-241-250
./bin/241_dfa_file_inclusion first.dfa second.dfa
./bin/242_dfa_file_shortest_word first.dfa
./bin/243_dfa_file_word_count first.dfa 10
./bin/244_dfa_file_scc_audit first.dfa
./bin/245_dfa_file_complement first.dfa > complement.dfa
./bin/246_dfa_file_intersection first.dfa second.dfa > intersection.dfa
./bin/247_dfa_file_reachable_trim first.dfa > reachable.dfa
./bin/248_dfa_file_minimize first.dfa > minimized.dfa
./bin/249_dfa_file_state_pair_witnesses first.dfa
./bin/250_dfa_file_graphviz first.dfa > machine.dot
```

**Notes:** Program 241 checks inclusion over all words, and 249 uses shortest witness searches on pairs of DFA states. Program 243 counts modulo 1,000,000,007, for lengths 0–100,000. Program 244 reports accepting cyclic SCCs, not all productive cycles. Program 246 limits its full Cartesian product to 32 states, which can be reduced afterward by program 247 or 248. Program 250 outputs DOT text suitable for Graphviz, not a rendered image. Each executable requires the shared repository header at compilation time.
