# Programs 221–230: Language Equivalence, Parsing, and Automata Testing

Ten independent ISO C11 programs with example-based or file-based inputs. They extend the existing repository to 230 programs.

| No. | Source | Contribution |
|---:|---|---|
| 221 | [`221_dfa_mutation_test_suite.c`](programs/221_dfa_mutation_test_suite.c) | Generate shortest test words that distinguish reference and mutated DFAs |
| 222 | [`222_nfa_universality_counterexample.c`](programs/222_nfa_universality_counterexample.c) | Exact NFA universality test via subset BFS with shortest rejected word |
| 223 | [`223_nfa_intersection_witness.c`](programs/223_nfa_intersection_witness.c) | Shortest accepted word in the intersection of two NFAs |
| 224 | [`224_moore_machine_equivalence.c`](programs/224_moore_machine_equivalence.c) | Check two Moore machines and return a shortest output-mismatch witness |
| 225 | [`225_cfg_first_follow_sets.c`](programs/225_cfg_first_follow_sets.c) | Iteratively compute FIRST, nullable, and FOLLOW sets for a fixed CFG |
| 226 | [`226_ll1_predictive_parser.c`](programs/226_ll1_predictive_parser.c) | Stack-based LL(1) parser for S -> a S b | epsilon |
| 227 | [`227_cyk_ambiguous_parse_count.c`](programs/227_cyk_ambiguous_parse_count.c) | Count parses in the ambiguous grammar S -> SS | a via dynamic programming |
| 228 | [`228_epsilon_nfa_shortest_word.c`](programs/228_epsilon_nfa_shortest_word.c) | Shortest accepted word in an epsilon-NFA using zero-one BFS |
| 229 | [`229_nfa_shuffle_language.c`](programs/229_nfa_shuffle_language.c) | Recognize shuffles of the two fixed words 01 and 10 |
| 230 | [`230_dfa_file_equivalence.c`](programs/230_dfa_file_equivalence.c) | File-based DFA equivalence checking with shortest counterexample |

## Build and run

```sh
make test-221-230
./bin/221_dfa_mutation_test_suite
./bin/222_nfa_universality_counterexample
./bin/223_nfa_intersection_witness
./bin/224_moore_machine_equivalence mutant
./bin/225_cfg_first_follow_sets
./bin/226_ll1_predictive_parser aabb
./bin/227_cyk_ambiguous_parse_count aaaa
./bin/228_epsilon_nfa_shortest_word
./bin/229_nfa_shuffle_language 0110
```

Program 221 uses three intentionally faulty DFA variants to generate shortest tests. Program 222 explores NFA subsets, program 223 explores the product of two NFA subsets, and program 224 checks a Moore-machine product. Program 225 iterates nullable, FIRST and FOLLOW sets for `S -> A B; A -> a A | ε; B -> b B | c`. Program 226 parses `S -> a S b | ε` with an LL(1) stack. Program 227 counts distinct parse trees for ambiguous `S -> S S | a` (up to 20 terminals). Program 228 finds the shortest word through epsilon transitions. Program 229 recognizes shuffles of the fixed words `01` and `10`, reporting accepting interleavings.

### Program 230: file-based DFA comparison

Pass two files using this plain-text format:

```text
3 0
0 0 1
1 0
1 2
1 0
```

The first line contains `state_count start_state`, the second has one `0` or `1` accepting flag per state, and each later line has the two destination states for inputs `0` and `1`, in state-number order. States are zero-based and at most 32 states are supported per file. This sample DFA recognizes words ending in `01`. Run:

```sh
./bin/230_dfa_file_equivalence first.dfa second.dfa
```

For equivalent machines the output is `EQUIVALENT`; otherwise the tool prints a shortest distinguishing word. Programs 221–229 use fixed pedagogical machines or grammars, not generic model-file inputs.
