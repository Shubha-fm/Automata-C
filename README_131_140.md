# Programs 131–140

Ten additional standalone C11 regular-language recognizers using binary, decimal, and letter alphabets.

- [131_dfa_binary_mod_23.c](programs/131_dfa_binary_mod_23.c): Binary integer divisible by 23
- [132_dfa_decimal_mod_11.c](programs/132_dfa_decimal_mod_11.c): Decimal integer divisible by 11
- [133_dfa_contains_abc.c](programs/133_dfa_contains_abc.c): Strings over abc containing substring abc
- [134_dfa_avoid_bb.c](programs/134_dfa_avoid_bb.c): Strings over ab without adjacent b
- [135_dfa_exactly_three_a.c](programs/135_dfa_exactly_three_a.c): Strings over ab containing exactly three a
- [136_dfa_a_count_mod_5.c](programs/136_dfa_a_count_mod_5.c): Strings over ab with a count divisible by five
- [137_dfa_binary_length_mod_7.c](programs/137_dfa_binary_length_mod_7.c): Binary strings of length divisible by seven
- [138_dfa_binary_has_exactly_one_11.c](programs/138_dfa_binary_has_exactly_one_11.c): Binary strings with exactly one overlapping occurrence of 11
- [139_dfa_ends_ab_or_ba.c](programs/139_dfa_ends_ab_or_ba.c): Strings over ab ending ab or ba
- [140_dfa_even_a_odd_c.c](programs/140_dfa_even_a_odd_c.c): Strings over abc with even a count and odd c count

Build with `make`, then test with `python3 tests/test_programs_131_140.py`.
