# Programs 101–110

Ten new C11 string recognizers for regular and nonregular languages. These are educational programs, not generic PDA or grammar parsing engines.

- [101_dyck_two_brackets.c](programs/101_dyck_two_brackets.c): Balanced () and [] with stack
- [102_anbncn_counter.c](programs/102_anbncn_counter.c): Recognize a^n b^n c^n using counters
- [103_cfg_palindrome.c](programs/103_cfg_palindrome.c): Recognize binary palindromes (CFG S->0S0|1S1|0|1|epsilon)
- [104_regex_a_star_b_plus.c](programs/104_regex_a_star_b_plus.c): Recognize regular expression a*b+
- [105_dfa_binary_mod_13.c](programs/105_dfa_binary_mod_13.c): Binary-value DFA modulo 13
- [106_dfa_avoid_1011.c](programs/106_dfa_avoid_1011.c): Recognize binary strings avoiding 1011
- [107_nfa_ends_abb.c](programs/107_nfa_ends_abb.c): NFA bitset simulation for strings ending abb
- [108_dfa_even_a_odd_b.c](programs/108_dfa_even_a_odd_b.c): Product DFA: even a and odd b counts
- [109_pda_anb2n.c](programs/109_pda_anb2n.c): Stack-style recognition of a^n b^(2n)
- [110_binary_no_000_or_111.c](programs/110_binary_no_000_or_111.c): DFA recognizer forbidding triple repeated bits

Build: `make` and run `python3 tests/test_programs_101_110.py`.
