# Programs 251–260: File-Based DFA Analysis, Enumeration, and Construction

This batch continues the shared [DFA text file format](README_241_250.md) introduced in programs 241–250. The executable programs use `include/dfa_io.h`, compile under ISO C11, and accept complete binary DFA files with 1–32 states.

| 252 | [`252_dfa_file_finiteness.c`](programs/252_dfa_file_finiteness.c) | Finite-language detection and exact accepted-word cardinality |
| 253 | [`253_dfa_file_reset_word.c`](programs/253_dfa_file_reset_word.c) | Shortest synchronizing word using subset BFS |

| 256 | [`256_dfa_file_symmetric_difference.c`](programs/256_dfa_file_symmetric_difference.c) | Symmetric difference product automaton |
| 257 | [`257_dfa_file_access_words.c`](programs/257_dfa_file_access_words.c) | Shortest words reaching each reachable DFA state |

## Compile and test

```bash
make test-251-260
./bin/251_dfa_file_universality model.dfa
./bin/252_dfa_file_finiteness model.dfa
./bin/253_dfa_file_reset_word model.dfa

```

## Shared DFA file format

The first line contains `state_count start_state`, the next line contains exactly one accepting flag (0 or 1) for each state, and the following lines contain two target states, for input `0` then input `1`, in state order. Example machine accepting binary words ending in `01`:

```text
3 0
0 0 1
1 0
1 2
1 0
```

All state identifiers start from 0. Transformation commands (255, 256, 260) output exactly this format, so their results can be passed to other file-based DFA commands. The output for 256 may require a product of up to 32 states. Program 255 accepts input DFAs with at most 10 states and will reject a reversal requiring more than 32 subset states.

## Interpretation and limits

Program 251 checks universality over all finite binary words, with the lexicographically earliest *shortest* counterexample. Program 252 detects productive cycles and, for finite languages, counts all accepted words exactly and reports the longest accepted-word length; empty languages report -1. Program 253 finds a shortest synchronizing word over all states (limit: 12 states). Program 254 ranks or unranks accepted binary words with a **fixed length up to 60**, with zero-based ranks. Program 257 reports state access sequences. Program 258 creates a transition-cover test suite for reachable transitions. Program 259 lists accepted words of a finite language in lexicographic order, capped at 1,000 outputs, and reports the full cardinality; it refuses infinite-language enumeration. Program 260 constructs the inverse homomorphic image, mapping binary input symbol 0 and 1 to supplied binary strings, with `e` denoting the empty string and up to 128 symbols per image.

These programs use finite explicit-state algorithms and bounded input sizes. They do not claim to process arbitrary large automata or infinite-state systems.
