# Programs 191–200: Advanced Automata and Language Algorithms

Ten standalone **ISO C11** implementations. Programs 191–200 extend the earlier examples with partition refinement, exact NFA equivalence, accepted-word ranking, generalized Büchi emptiness and CYK recognition.

| No. | Program | Description | Input |
|---:|---|---|---|
| 191 | [`191_hopcroft_dfa_minimization.c`](programs/191_hopcroft_dfa_minimization.c) | Hopcroft partition refinement of a six-state DFA | Built-in example |
| 192 | [`192_dfa_matrix_word_count.c`](programs/192_dfa_matrix_word_count.c) | Count accepted binary words using matrix exponentiation | Command line |
| 193 | [`193_nfa_dfa_exact_equivalence.c`](programs/193_nfa_dfa_exact_equivalence.c) | On-the-fly exact equivalence of an NFA and a DFA, with witness | Built-in example |
| 194 | [`194_nfa_shortest_accepted_word.c`](programs/194_nfa_shortest_accepted_word.c) | Breadth-first subset search for the shortest NFA-accepted word | Built-in example |
| 195 | [`195_dfa_lexicographic_unranking.c`](programs/195_dfa_lexicographic_unranking.c) | Find the kth lexicographic word accepted by a parity DFA | Command line |
| 196 | [`196_nfa_ambiguity_witness.c`](programs/196_nfa_ambiguity_witness.c) | Find the shortest word with multiple accepting NFA runs | Built-in example |
| 197 | [`197_generalized_buchi_scc.c`](programs/197_generalized_buchi_scc.c) | Check two-set generalized Büchi acceptance using SCCs | Built-in example |
| 198 | [`198_mealy_transducer_composition.c`](programs/198_mealy_transducer_composition.c) | Compose bit-complement and binary-to-Gray Mealy transducers | Command line |
| 199 | [`199_cfg_cyk_membership.c`](programs/199_cfg_cyk_membership.c) | CYK membership for a nontrivial fixed Chomsky-normal-form grammar | Command line |
| 200 | [`200_dfa_reachability_productivity_audit.c`](programs/200_dfa_reachability_productivity_audit.c) | Audit reachable, productive, dead, and unreachable DFA states | Built-in example |

## Build and test

```sh
make test-191-200
./bin/191_hopcroft_dfa_minimization
./bin/192_dfa_matrix_word_count 1000000
./bin/193_nfa_dfa_exact_equivalence mutant
./bin/194_nfa_shortest_accepted_word
./bin/195_dfa_lexicographic_unranking 3 2
./bin/196_nfa_ambiguity_witness
./bin/197_generalized_buchi_scc
./bin/198_mealy_transducer_composition 1011
./bin/199_cfg_cyk_membership baaba
./bin/200_dfa_reachability_productivity_audit
```

The equivalence and ambiguity examples use specified finite machines. The CYK grammar is `S -> AB | BC`, `A -> BA | a`, `B -> CC | b`, `C -> AB | a`. The matrix exponentiation counts even-one-parity binary words modulo 1,000,000,007. The kth-word selection uses zero-based ranking for length at most 60. These are illustrative algorithms, not generic file-based parsers for arbitrary automata or grammars.
