# Programs 281–290: Probabilistic DFA Analysis, Monoids, and Regular Quotients

Ten ISO C11 programs that extend the reusable [binary DFA text format](README_241_250.md). All programs use `include/dfa_io.h` and read complete binary DFAs with 1–32 states. Programs 287–290 output DFA text files that other toolkit programs can read.

| # | Source | Function |
|---:|---|---|
| 281 | [`281_dfa_file_biased_acceptance.c`](programs/281_dfa_file_biased_acceptance.c) | Biased Bernoulli acceptance probability of a file-based DFA |
| 282 | [`282_dfa_file_hitting_probability.c`](programs/282_dfa_file_hitting_probability.c) | Probability of ever reaching an accepting state by a time bound |
| 283 | [`283_dfa_file_expected_prefix_accepts.c`](programs/283_dfa_file_expected_prefix_accepts.c) | Expected count of accepting prefixes, including the empty prefix |
| 284 | [`284_dfa_file_transition_monoid.c`](programs/284_dfa_file_transition_monoid.c) | Enumerate the transition monoid of a DFA with at most five states |
| 285 | [`285_dfa_file_aperiodicity.c`](programs/285_dfa_file_aperiodicity.c) | Decide DFA transition-monoid aperiodicity |
| 286 | [`286_dfa_file_rooted_isomorphism.c`](programs/286_dfa_file_rooted_isomorphism.c) | Check rooted isomorphism of reachable DFA subgraphs |
| 287 | [`287_dfa_file_swap_symbols.c`](programs/287_dfa_file_swap_symbols.c) | Exchange transitions on input zero and one |
| 288 | [`288_dfa_file_right_quotient_regular.c`](programs/288_dfa_file_right_quotient_regular.c) | Right quotient of a DFA language by another regular language |
| 289 | [`289_dfa_file_left_quotient_regular.c`](programs/289_dfa_file_left_quotient_regular.c) | Left quotient of a DFA language by another regular language |
| 290 | [`290_dfa_file_bounded_length_filter.c`](programs/290_dfa_file_bounded_length_filter.c) | Filter a DFA language to lengths at most or exactly K |

## Commands

```sh
make test-281-290
./bin/281_dfa_file_biased_acceptance sample.dfa 10 0.3
./bin/282_dfa_file_hitting_probability sample.dfa 10 0.3
./bin/283_dfa_file_expected_prefix_accepts sample.dfa 10 0.3
./bin/284_dfa_file_transition_monoid sample.dfa
./bin/285_dfa_file_aperiodicity sample.dfa
./bin/286_dfa_file_rooted_isomorphism a.dfa b.dfa
./bin/287_dfa_file_swap_symbols sample.dfa > swapped.dfa
./bin/288_dfa_file_right_quotient_regular a.dfa b.dfa > right_quotient.dfa
./bin/289_dfa_file_left_quotient_regular a.dfa b.dfa > left_quotient.dfa
./bin/290_dfa_file_bounded_length_filter sample.dfa 5 > at_most_five.dfa
./bin/290_dfa_file_bounded_length_filter sample.dfa 5 exact > exactly_five.dfa
```

## Interpretation

Programs 281–283 assume independently sampled binary symbols, with the given probability for input `1`. Program 281 reports final acceptance probability, 282 reports the probability of visiting any accepting state at or before N steps, and 283 reports the expected number of accepted prefixes including the empty prefix. Programs 284–285 enumerate the complete transition monoid (at most five states), testing aperiodicity by checking whether powers of every transformation eventually stabilize. Program 286 checks rooted isomorphism of the **reachable** machine parts; unreachable states do not affect this comparison. Programs 288 and 289 compute the regular-language quotients `L(A)/L(B) = {x: exists y in L(B), xy in L(A)}` and `L(B)^(-1)L(A) = {x: exists y in L(B), yx in L(A)}`. Program 290 constructs a product with a bounded length counter, optionally enforcing an exact length.

## Limits and testing

Probability calculations allow 0–100,000 input symbols, with probabilities in [0,1]. Transition monoid and aperiodicity tools support at most five states. Program 289 supports at most ten states in the first DFA because its subset construction produces at most 32 output states. The bounded length filter limits K to 30 and the total number of output states to 32. Regression tests use independent Python reference implementations on hand-built and seeded random DFAs, compare generated-language membership, and verify failure cases.
