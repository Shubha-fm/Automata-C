# Programs 271–280: Advanced Regular-Language Constructions and DFA Analysis

Ten new C11 programs that extend the reusable [binary DFA file format](README_241_250.md), with all transformations emitting compatible automata.

| No. | Source | Purpose |
|---:|---|---|
| 271 | [`271_dfa_file_factor_closure.c`](programs/271_dfa_file_factor_closure.c) | All contiguous substrings of words in a DFA language |
| 272 | [`272_dfa_file_subsequence_closure.c`](programs/272_dfa_file_subsequence_closure.c) | Downward closure under subsequence deletion |
| 273 | [`273_dfa_file_supersequence_closure.c`](programs/273_dfa_file_supersequence_closure.c) | Upward closure under symbol insertion |
| 274 | [`274_dfa_file_concatenation.c`](programs/274_dfa_file_concatenation.c) | Language concatenation via an epsilon NFA |
| 275 | [`275_dfa_file_kleene_star.c`](programs/275_dfa_file_kleene_star.c) | Kleene star with subset determinization |
| 276 | [`276_dfa_file_access_diameter.c`](programs/276_dfa_file_access_diameter.c) | Longest shortest access word and BFS access witnesses |
| 277 | [`277_dfa_file_unary_periodicity.c`](programs/277_dfa_file_unary_periodicity.c) | Unary preperiod and period on repeated zero input |
| 278 | [`278_dfa_file_length_periodicity.c`](programs/278_dfa_file_length_periodicity.c) | Eventual periodicity of accepted word lengths |
| 279 | [`279_dfa_file_expected_hitting_time.c`](programs/279_dfa_file_expected_hitting_time.c) | Expected time to an accepting state under fair random input |
| 280 | [`280_dfa_file_uniform_sampler.c`](programs/280_dfa_file_uniform_sampler.c) | Seeded uniform sample of an accepted fixed-length word |

## Build and run

```sh
make test-271-280
./bin/271_dfa_file_factor_closure model.dfa > factors.dfa
./bin/272_dfa_file_subsequence_closure model.dfa > subsequences.dfa
./bin/273_dfa_file_supersequence_closure model.dfa > supersequences.dfa
./bin/274_dfa_file_concatenation first.dfa second.dfa > concatenated.dfa
./bin/275_dfa_file_kleene_star model.dfa > star.dfa
./bin/276_dfa_file_access_diameter model.dfa
./bin/277_dfa_file_unary_periodicity model.dfa
./bin/278_dfa_file_length_periodicity model.dfa
./bin/279_dfa_file_expected_hitting_time model.dfa
./bin/280_dfa_file_uniform_sampler model.dfa 8 42
```

## Formal meaning

For language L over {0,1}, **factor closure** contains every contiguous substring of any word in L. **Subsequence downward closure** contains every word obtained by deleting zero or more symbols from some word of L. **Supersequence upward closure** contains all words containing at least one accepted word as a subsequence. Program 274 constructs concatenation L(A)L(B), while 275 constructs L*. Programs 277 and 278 report a finite preperiod followed by a repeating acceptance pattern: unary words 0ⁿ and lengths of words over the full binary alphabet, respectively. Program 279 reports the expected number of independent fair-coin input symbols before first entering an accepting state; it prints INFINITE if the expected hitting time diverges. Program 280 draws a uniformly selected accepted word at a chosen length, with a deterministic PRNG seed, or reports that no such word exists.

## Limits and tests

The closure and periodicity tools that use bitmask subset construction accept at most 10 input states and cap determinized outputs at 32 states. Concatenation permits at most 10 combined NFA states; Kleene star at most 9 original states. Uniform sampling supports lengths 0–50, using 64-bit counts without overflow. Every program accepts the shared complete binary DFA format (1–32 states). The automated tests use independent Python reference calculations, random DFA examples, and language-membership comparisons.
