# Programs 201–210: Automata Word Operations, Quotients, and Language Analysis

Ten standalone C11 programs. Most use complete built-in automata; the Hamming recognizer, Büchi word evaluator, and partial-DFA completion tool take user input.

| # | C source | Purpose |
|---:|---|---|
| 201 | [`201_dfa_accepted_word_rank.c`](programs/201_dfa_accepted_word_rank.c) | Find a binary word's zero-based lexicographic rank among even-parity words |
| 202 | [`202_dfa_transition_monoid.c`](programs/202_dfa_transition_monoid.c) | Enumerate the finite transition monoid of a sample DFA |
| 203 | [`203_dfa_iid_accept_probability.c`](programs/203_dfa_iid_accept_probability.c) | Compute DFA acceptance probability for uniformly random binary words |
| 204 | [`204_nfa_language_inclusion_witness.c`](programs/204_nfa_language_inclusion_witness.c) | Exact NFA language inclusion against a DFA using a product-state BFS |
| 205 | [`205_dfa_inverse_homomorphism.c`](programs/205_dfa_inverse_homomorphism.c) | Recognize the inverse image of ends-in-01 under a binary substitution |
| 206 | [`206_regex_brzozowski_derivative.c`](programs/206_regex_brzozowski_derivative.c) | Derivative-state recognition of the fixed regular expression 0*1 |
| 207 | [`207_dfa_hamming_distance_one.c`](programs/207_dfa_hamming_distance_one.c) | Hamming-distance-one language recognizer for a supplied binary target |
| 208 | [`208_buchi_ultimately_periodic_word.c`](programs/208_buchi_ultimately_periodic_word.c) | Check Büchi acceptance of an ultimately periodic infinite word u(v)^omega |
| 209 | [`209_cyk_parse_tree_witness.c`](programs/209_cyk_parse_tree_witness.c) | Construct an explicit CYK parse tree for a fixed CNF grammar |
| 210 | [`210_partial_dfa_sink_completion.c`](programs/210_partial_dfa_sink_completion.c) | Complete a partial binary DFA by adding a rejecting sink state |

## Build and test

```sh
make test-201-210
./bin/201_dfa_accepted_word_rank 110
./bin/202_dfa_transition_monoid
./bin/203_dfa_iid_accept_probability 8
./bin/204_nfa_language_inclusion_witness
./bin/205_dfa_inverse_homomorphism aba
./bin/206_regex_brzozowski_derivative 0001
./bin/207_dfa_hamming_distance_one 101 111
./bin/208_buchi_ultimately_periodic_word '' 01
./bin/209_cyk_parse_tree_witness baaba
```

Program 201 is the inverse of lexicographic unranking (program 195) for even-one-parity binary languages. Program 202 generates the finite transition monoid of the built-in ends-in-01 DFA. Program 203 uses uniform independent input symbols; it is not general probabilistic model checking. Program 204 performs an exact product/subset check for its built-in NFA and DFA. Program 206 illustrates derivatives for the **fixed** regex `0*1`, not arbitrary regex parsing. Program 208 checks Büchi acceptance of infinite words described by a finite prefix and nonempty period. Program 209 uses a fixed CNF grammar and produces a parse-tree witness.

## Partial DFA format for program 210

Input file: first line `n start`, second line `n` final-state flags, followed by exactly `n` rows containing `on0 on1` transition targets (zero-based indices). Use `-1` for missing transitions. The tool adds one rejecting sink if at least one transition is missing. Example:

```text
2 0
0 1
1 -1
1 0
```

Run `./bin/210_partial_dfa_sink_completion example.dfa`.
