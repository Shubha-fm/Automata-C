# Automata examples 121–130

Standalone C11 recognizers for binary regular languages and alphabets {a,b} and {a,b,c}.

- [121_dfa_count_01_mod_3.c](programs/121_dfa_count_01_mod_3.c): Number of 01 occurrences divisible by three
- [122_dfa_count_10_mod_2.c](programs/122_dfa_count_10_mod_2.c): Even number of 10 occurrences
- [123_dfa_ends_same_two.c](programs/123_dfa_ends_same_two.c): Binary strings whose last two digits agree
- [124_dfa_first_last_same.c](programs/124_dfa_first_last_same.c): Nonempty binary strings starting and ending with same symbol
- [125_dfa_contains_010_and_101.c](programs/125_dfa_contains_010_and_101.c): Binary strings containing both 010 and 101
- [126_dfa_no_010_or_101.c](programs/126_dfa_no_010_or_101.c): Binary strings avoiding 010 and 101
- [127_dfa_a_mod_3_b_mod_2.c](programs/127_dfa_a_mod_3_b_mod_2.c): a count multiple of 3 and b count even
- [128_dfa_odd_length_ends_0.c](programs/128_dfa_odd_length_ends_0.c): Odd-length binary strings ending in zero
- [129_dfa_binary_mod_19.c](programs/129_dfa_binary_mod_19.c): Binary number divisible by 19
- [130_dfa_abc_ends_ab.c](programs/130_dfa_abc_ends_ab.c): Strings over a,b,c ending with ab

Run `make` and then `python3 tests/test_programs_121_130.py`.
