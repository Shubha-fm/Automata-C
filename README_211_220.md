# Programs 211–220: Advanced Automata Algorithms

This batch adds ten C11 programs emphasizing language-theoretic witnesses, counting, ambiguity, grammar parsing, and finite-state transformations. They are standalone educational implementations, with bounded inputs where noted.

| No. | Source | Description |
|---:|---|---|
| 211 | [`211_dfa_pumping_witness.c`](programs/211_dfa_pumping_witness.c) | Construct and validate a pumping decomposition for an infinite DFA language |
| 212 | [`212_nfa_count_distinct_words.c`](programs/212_nfa_count_distinct_words.c) | Count distinct NFA-accepted binary words without double-counting paths |
| 213 | [`213_dfa_next_accepted_word.c`](programs/213_dfa_next_accepted_word.c) | Find the next accepted same-length word in lexicographic order |
| 214 | [`214_weighted_nfa_viterbi_path.c`](programs/214_weighted_nfa_viterbi_path.c) | Recover a minimum-cost accepting state sequence in a weighted NFA |
| 215 | [`215_dfa_pair_synchronization.c`](programs/215_dfa_pair_synchronization.c) | Check pair mergeability as a synchronizing-DFA criterion |
| 216 | [`216_nfa_exact_ambiguity.c`](programs/216_nfa_exact_ambiguity.c) | Check NFA ambiguity exactly via a product of two independent runs |
| 217 | [`217_earley_cfg_membership.c`](programs/217_earley_cfg_membership.c) | Earley membership for S -> a S b | epsilon |
| 218 | [`218_regular_grammar_to_nfa.c`](programs/218_regular_grammar_to_nfa.c) | Build and simulate an NFA from a user-supplied right-linear grammar |
| 219 | [`219_nfa_epsilon_elimination.c`](programs/219_nfa_epsilon_elimination.c) | Eliminate epsilon transitions and exhaustively cross-check the result |
| 220 | [`220_dfa_finite_language_cardinality.c`](programs/220_dfa_finite_language_cardinality.c) | Determine finite-language cardinality or detect infinite accepted words |

### Right-linear grammar example (218)

Save a file `grammar.rg`:

```text
S
4
S 0 S
S 1 A
A 0 A
A 1 #
```

The first line is the start nonterminal, the second is the number of productions, and subsequent lines are `FROM SYMBOL TO`. Nonterminals are `A` through `Z`, terminals are `0` and `1`, `e` denotes epsilon, and `#` indicates the accepting terminal destination. `A e #` expresses an epsilon production. The grammar above generates `0*10*1`.

```sh
./bin/218_regular_grammar_to_nfa grammar.rg 001001
```

### Scope

Program 211 constructs a pumping example for a built-in DFA. Program 212 counts distinct accepted words, not NFA runs. Program 213 finds the strict lexicographic successor for the even-parity language. Program 214 recovers a weighted minimum-cost run. Program 215 applies the pair-mergeability criterion for complete DFAs. Program 216 uses two synchronized NFA runs to check ambiguity for the included example machines. Program 217 uses the Earley algorithm for `S -> a S b | ε` (maximum input length 32). Program 218 builds an NFA from a supplied grammar. Program 219 performs epsilon elimination and checks all words of length up to 10. Program 220 detects infiniteness and otherwise counts the complete finite language of the built-in DFA.
