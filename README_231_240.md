# Programs 231–240: Advanced Automata Testing and Verification

This batch adds ten independent C11 examples covering conformance-test generation, automata equivalence, weighted search, grammar analysis, probability, bounded PDA exploration, finite-trace monitoring and Büchi witnesses.

| No. | Source | What it demonstrates |
|---:|---|---|
| 231 | [`231_dfa_w_method_tests.c`](programs/231_dfa_w_method_tests.c) | Construct a W-method conformance suite for a three-state DFA |
| 232 | [`232_nfa_bounded_language_comparison.c`](programs/232_nfa_bounded_language_comparison.c) | Compare two NFAs on every binary word up to a chosen length |
| 233 | [`233_weighted_shortest_accepted_word.c`](programs/233_weighted_shortest_accepted_word.c) | Dijkstra search for the least-cost word accepted by a weighted automaton |
| 234 | [`234_cfg_nullable_unit_closure.c`](programs/234_cfg_nullable_unit_closure.c) | Compute nullable nonterminals and unit-production closure of a CFG |
| 235 | [`235_ll1_parse_table_generator.c`](programs/235_ll1_parse_table_generator.c) | Compute LL(1) predictive table from a fixed grammar using FIRST and FOLLOW |
| 236 | [`236_dfa_symbol_probability.c`](programs/236_dfa_symbol_probability.c) | Compute DFA state probabilities under biased independent binary input |
| 237 | [`237_pda_bounded_configuration_bfs.c`](programs/237_pda_bounded_configuration_bfs.c) | Explore bounded pushdown configurations for the language a^n b^n |
| 238 | [`238_finite_trace_temporal_monitor.c`](programs/238_finite_trace_temporal_monitor.c) | Evaluate safety and bounded-response properties on finite binary traces |
| 239 | [`239_nfa_distinct_word_enumerator.c`](programs/239_nfa_distinct_word_enumerator.c) | Enumerate distinct NFA-accepted binary words of a specified length |
| 240 | [`240_generalized_buchi_lasso_witness.c`](programs/240_generalized_buchi_lasso_witness.c) | Construct a witness lasso visiting two Büchi acceptance sets infinitely often |

## Build and test

```sh
make test-231-240
./bin/231_dfa_w_method_tests
./bin/232_nfa_bounded_language_comparison 10
./bin/232_nfa_bounded_language_comparison 10 mutant
./bin/233_weighted_shortest_accepted_word
./bin/234_cfg_nullable_unit_closure
./bin/235_ll1_parse_table_generator
./bin/236_dfa_symbol_probability 2 0.3
./bin/237_pda_bounded_configuration_bfs aabb
./bin/238_finite_trace_temporal_monitor 010
./bin/239_nfa_distinct_word_enumerator 4
./bin/240_generalized_buchi_lasso_witness
```

**Scope and interpretation:** Program 231 generates a W-method-like suite for an explicitly specified three-state DFA, using a state cover and characterization set. Program 232 performs *bounded* NFA language comparison, not an unrestricted equivalence proof. Program 233 uses nonnegative-weight Dijkstra search. Program 234 computes nullable and unit closure for a fixed grammar with `S -> A | b`, `A -> B | ε`, and `B -> a | A`. Program 235 derives an LL(1) table for `E -> T R`, `R -> + T R | ε`, `T -> i`. Program 236 propagates a parity DFA's state distribution for independent input symbols, with a supplied probability of reading `1`. Program 237 does BFS over bounded pushdown configurations for `a^n b^n` (up to 24 input symbols). Program 238 uses explicitly finite-trace semantics: a terminal `1` violates the strong-next response obligation. Program 239 lists unique accepted words of a fixed length (0–12). Program 240 finds a lasso visiting two acceptance sets infinitely often for its built-in generalized Büchi automaton.

These are educational tools, not replacements for general automata libraries or full model-checking frameworks.
