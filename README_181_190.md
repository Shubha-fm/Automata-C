# Programs 181–190: Weighted, Probabilistic, Timed, and Transducer Models

Ten standalone C11 examples that introduce models and verification exercises beyond basic DFA recognition. Each source file is independent and the Makefile builds them into `bin/`.

| No. | Source | Example |
|---:|---|---|
| 181 | [`181_weighted_nfa_min_cost.c`](programs/181_weighted_nfa_min_cost.c) | Minimum accepting cost of a nondeterministic weighted finite automaton |
| 182 | [`182_probabilistic_finite_automaton.c`](programs/182_probabilistic_finite_automaton.c) | Probabilistic finite automaton with acceptance threshold 0.5 |
| 183 | [`183_mealy_binary_to_gray.c`](programs/183_mealy_binary_to_gray.c) | Mealy transducer converting binary digits into Gray code |
| 184 | [`184_mealy_bit_stuffing.c`](programs/184_mealy_bit_stuffing.c) | Mealy-style bit stuffing: insert zero after five consecutive ones |
| 185 | [`185_mealy_bit_unstuffing.c`](programs/185_mealy_bit_unstuffing.c) | Inverse of bit-stuffing transducer with malformed-input rejection |
| 186 | [`186_levenshtein_automaton_distance_one.c`](programs/186_levenshtein_automaton_distance_one.c) | Threshold-one Levenshtein recognizer for binary words |
| 187 | [`187_trie_keyword_dfa.c`](programs/187_trie_keyword_dfa.c) | Dynamically construct a trie DFA for six compiler keywords |
| 188 | [`188_timed_automaton_guard.c`](programs/188_timed_automaton_guard.c) | Timed transition monitor: consecutive timestamps must be within ten units |
| 189 | [`189_buchi_accepting_lasso.c`](programs/189_buchi_accepting_lasso.c) | Find a reachable Büchi accepting cycle and show a lasso witness |
| 190 | [`190_dfa_transition_validator.c`](programs/190_dfa_transition_validator.c) | Validate a complete deterministic binary transition table from a text file |

## Compile and test

```sh
make test-181-190
./bin/181_weighted_nfa_min_cost 01
./bin/182_probabilistic_finite_automaton 1
./bin/183_mealy_binary_to_gray 1011
./bin/184_mealy_bit_stuffing 111111
./bin/185_mealy_bit_unstuffing 1111101
./bin/186_levenshtein_automaton_distance_one 101 1001
./bin/187_trie_keyword_dfa while
./bin/188_timed_automaton_guard 0,4,9
./bin/189_buchi_accepting_lasso
```

Program 181 uses the tropical (minimum-cost) semiring over a fixed three-state nondeterministic automaton. Program 182 computes a final-state probability, classifying at threshold 0.5. Programs 183–185 are practical finite-state transducers. Program 186 uses edit-distance dynamic programming for the Levenshtein distance-one language (target supplied on the command line). Program 187 constructs a trie of six keyword strings at runtime. Program 188 implements a **simplified timestamp guard monitor**, not a complete timed-automata model checker. Program 189 searches for a reachable Büchi accepting cycle in a built-in graph. Program 190 validates a supplied transition table.

## DFA table file format (program 190)

The first line gives the number of states and initial state. The second gives one `0` or `1` acceptance flag per state. Then provide precisely `2 * states` transition triples `from_state symbol to_state`, in any order. All states are numbered from 0. For example:

```text
3 0
0 0 1
0 0 1
0 1 0
1 0 1
1 1 2
2 0 1
2 1 0
```

Run `./bin/190_dfa_transition_validator path/to/model.dfa`. Duplicate, missing, out-of-range, or malformed transitions are rejected. These programs are educational examples; support for general arbitrary weighted automata, timed-automata zones, and probabilistic model checking is not claimed.
